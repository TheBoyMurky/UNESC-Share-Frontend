# Contexto — UnescShare Frontend

## Projeto e arquitetura

Catalogo academico BitTorrent: Instituicao -> Curso -> Disciplina -> Material. Material representa metadados, nao arquivo hospedado. Torrent e Magnet sao entidades independentes, varias por Material. Nenhuma tela deve introduzir upload direto de conteudos academicos.

Vue 3/Vite/TypeScript em repositorio separado; navegador -> HTTP REST /api/v1 -> Spring Boot -> PostgreSQL. O cliente BitTorrent do usuario obtem o conteudo na rede, nao no servidor UnescShare.
