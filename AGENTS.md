# Instrucoes do projeto para agentes

## Premissas e stack

- UnescShare e um catalogo academico BitTorrent, nao hospedagem de conteudos. Somente `.torrent` e Magnet URIs; nunca upload de PDF/EPUB/MP4/ZIP ou conteudos academicos.
- Material e o registro/metadados; Torrent e Magnet sao entidades independentes, varias por Material. Backend e a autoridade dos dados/permissoes.
- Vue 3/Vite/TypeScript neste repositorio; backend Java 21/Spring Boot/PostgreSQL na pasta irma ../UNESC-Share-Backend, API /api/v1. Nao mover ou recriar o backend aqui.
- Node ^22.18.0 ou >=24.12.0; validado com Node22.23.3/npm10.9.9. Usar npm e manter package-lock.json.

## Desenvolvimento

- Incremental, com codigo completo nos arquivos, instrucao de execucao/teste e contexto atualizado. Apresentar alternativas/impactos antes de fixar decisoes arquiteturais indefinidas.
- Organizacao em src/features, configuracao em src/config e estilos/recursos em src/assets. Alias @ para src. Componentes script setup/TypeScript; nao usar v-html com texto nao confiavel.
- Scripts: npm ci, npm run dev, npm run test, npm run type-check, npm run build, npm run verify. Testes atuais usam node:test nativo com importacao TypeScript suportada pelo Node exigido.
- Dev localhost:5173/strictPort, preview localhost:4173; origens distintas para CORS. Nao expor servidor publicamente automaticamente.
- VITE_API_BASE_URL e publica, padrao http://localhost:8080/api/v1. Nunca segredos/JWT_SECRET/senhas/credenciais no bundle, VITE_*, logs ou Git. Nao versionar .env real.
- Preservar mudancas existentes, usar apply_patch para edicoes e manter README/docs/CONTEXTO_PROJETO.md atualizados. Nao configurar remoto nem realizar commit/push sem solicitacao.
- Nao executar Docker nem sudo para Docker: enviar comandos ao usuario e aguardar. Maven/backend podem ser executados quando pertinentes/autorizados, respeitando permissoes do ambiente.

## Contratos a preservar

- Bearer JWT somente em Authorization, API stateless sem cookies/sessao/Basic/form login. TTL padrao15min, configuravel1..30; sem refresh/revogacao imediata. Cadastro publico sempre USUARIO.
- Em 22/10/2026, o usuario escolheu explicitamente sessionStorage (em vez da recomendacao de memoria) e aprovou Vue Router. Salvar somente accessToken/expiresAt na chave unescshare.auth.v1; nunca senha, perfil ou dados pessoais. Restaurar apenas apos /usuarios/me; nao mudar para localStorage/cookies silenciosamente. Risco XSS e copiabilidade de abas documentados. Pinia/Axios/UI kit nao aprovados; fetch nativo ja implementado.
- Cadastro/login publicos; demais rotas de negocio autenticadas, inclusive pesquisa PUBLICADO. Escrita da estrutura academica apenas ADMINISTRADOR; usuarios gerenciam proprios materiais. Equipe MODERADOR/ADMINISTRADOR usa rotas especificas, sem impersonar autor.
- Material nasce PENDENTE; edicao/adicao em PUBLICADO volta a PENDENTE. Detalhe privado apenas autor/equipe; terceiros404. REMOVIDO logico sem restauracao. Em25/10/2026 usuario escolheu manter autoaprovacao para MODERADOR e ADMINISTRADOR, inclusive material proprio. Nao aplicar conflito de Denuncia a Material.
- CORS expoe Location/Content-Disposition sem credenciais; requisicoes permitem Authorization/Content-Type. Nao definir Content-Type de FormData manualmente nem colocar JWT em URL.
- Erros MVC ProblemDetail; falhas Bearer podem ter corpo vazio. Verificar status/Content-Type antes de JSON;204 sem corpo e download bem-sucedido blob.
- Paginas: content + page{size,number,totalElements,totalPages}, page>=0, size1..100/padrao20, ordenacao fixa; UUID strings, enums maiusculos e datas ISO/UTC.
- TorrentResponse.tamanho mede metainfo. Arquivo torrent v1 ate2MiB/arquivo e3MiB/requisicao, max10Torrents/10Magnets. Magnets v1/v2SHA256; hibridos/multiplosxt pendentes. Mesmo hash Torrent+Magnet apenas no mesmo Material.
- Avaliacao numerica JSON0.00..5.00, ate2casas, exibicao pt-BR; uma por usuario/Material, sem autoavaliacao. Textos escapados, nunca HTML confiavel.
- Denunciante/autor do Material impedidos de moderar denuncia, inclusive administrador; procedencia nao bloqueia Material automaticamente. Nao aplicar essa politica a outros fluxos sem aprovacao.
